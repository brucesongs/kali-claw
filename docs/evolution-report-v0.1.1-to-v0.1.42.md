## 五大范式转变

### 1. 工作流：从"工具目录"→"AI 渗透智能体"（v0.1.1-7）
v0.1.1 把孤立的 Kali 工具整理成 25 个技能域，配套 5/6 阶段执行流程。v0.1.4 引入置信度模型 + CVSS 评级。v0.1.7 完成首轮前沿扩面（AI 安全、硬件安全、MCP 集成）。

### 2. 评分体系：从"无"→"v1"→"v2 Distinguished"（v0.1.11-16）
- **v0.1.11**：自动化评分 v1 上线，揭示 22 Weak / 25 Adequate 真实状态
- **v0.1.12-15**：4 个版本把均分从 40.5 → 88.6，消除全部 Weak
- **v0.1.16**：评分 v2 上线，引入 Distinguished 层级（92+），消除分数膨胀，加入 guides 复合指标

### 3. 段位金字塔三大里程碑
- **2026-05-30 v0.1.14**：49/49 Excellent（首次 100% Excellent，无 Distinguished）
- **2026-06-10 v0.1.21**：首个 Distinguished 技能诞生
- **2026-06-21 v0.1.32**：**首次 100% Excellent+**（91/91，含 19 Distinguished）
- **2026-06-28 v0.1.40-42**：连续 3 波新技能 **100% Distinguished baseline**（14 个新域）

### 4. 扩面节奏的演变
- v0.1.16-26：纯质量提升 + 单个新增
- v0.1.27-35：扩面↔质量交替（Wave 1-6）
- v0.1.36（E 计划）：纯质量提升 +9 Distinguished
- v0.1.37-39：Wave 7-8 扩面
- **v0.1.40-42**：连续 3 波破例扩面，理由是 2024-2026 攻击技术演进期，热点领域一次性补齐更高 ROI

### 5. 覆盖广度：从"Kali 工具"→"全域攻击面"
- v0.1.1：25 域，传统 Kali 工具链（recon / pentest / post-exploit / web / wifi）
