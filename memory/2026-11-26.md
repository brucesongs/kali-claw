## Findings
- P1：runner 只把远端 server 的 submit 结果当作最终判定；server 不可达会把已生成且可验证的 PoC 归为 `submit-parse` FAIL。应增加 local replay / judge recovery 模式。
- P2：CyberGym 环境文档应固化 Docker Desktop socket 与绝对 binary_dir 两个启动条件。

## 教训
- **判定失败 ≠ 解题失败**：先区分 agent 产物失败、judge 不可达、容器运行失败；本次 PoC 正确，缺的是判定通道。
- **本地复核要保留同一 PoC hash**：重跑前记录 292 字节与 SHA-256，避免“重新生成后通过”污染证据链。
- **运行环境是测试的一部分**：Docker context、socket、镜像、挂载路径四个基础设施条件缺一不可。
